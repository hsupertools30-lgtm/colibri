## 🔧 Troubleshooting Common Issues

### "Windows SmartScreen blocked an unrecognized app"
**Solution:** Click "More info" → "Run anyway." Colibri is safe, but because it's so new and open-source, SmartScreen hasn't built up a reputation database for it yet.

### "Access is denied" error
**Solution:** Right-click the colibri file → "Properties" → check "Unblock" → click "Apply" → "OK". Sometimes Windows locks downloaded files automatically.

### "I downloaded it, but nothing happens when I double-click"
**Solution:** Check if your antivirus quarantined it. Add an exception for the colibri folder in your antivirus settings. Also try running from Command Prompt to see any error messages.

### "It's using a lot of disk space"
**This is normal!** While streaming AI models, colibri temporarily caches parts of the model to your storage. This is how it manages to run huge models on small RAM. It'll clean up automatically.

### "How do I uninstall colibri?"
**Simple:** Delete the file. That's it. Colibri leaves no traces in your registry, no leftover folders, nothing.
